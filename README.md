## 🎯 How I Take Notes

Every entry follows a fixed template with a deliberate **two-layer interview
section**: Layer 1 is recall ("what does this command do"), Layer 2 is the
follow-up an interviewer actually asks next ("why is it stealthier / when would
you use it instead"). The reasoning layer is where real understanding shows.

See [`00-templates/`](./00-templates/) for the templates, and
[`01-tryhackme/phase1-foundations/Nmap.md`](./01-tryhackme/phase1-foundations/Nmap.md)
for a worked example of the depth I aim for.
